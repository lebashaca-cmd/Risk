## Reading a command page

- The first line is the command and an example of how to type it.
- **Needs …** means you need that Discord permission in the server. **Anyone can use it** means no permission is required.
- Commands with parts, like `!giveaway start` or `!autoreact add`, are listed separately for each part.
- Your server may restrict a command with [command rules](command-rules) or switch it off.
