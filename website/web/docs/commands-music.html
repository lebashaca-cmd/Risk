    Music commands

    Play music in a voice channel from YouTube, SoundCloud, Spotify and more: play, queue, skip, loop, volume and seek. The bot owner needs to run a Lavalink server. Anyone can use a command unless it says it needs a permission. If your server changed the prefix, use that instead of !.

    !8d#

    Anyone can use it

    Toggles 8D audio, where the sound circles your head. Use headphones.

    !bass#

    Anyone can use it

    Changes the bass boost. Use off, low, medium, high, extreme or a number from 0 to 100.

    Try it: !bass high | !bass 40 | !bass off (no level shows the current one)

    !equalizer#

    Anyone can use it

    Applies an equalizer preset. Presets: flat, bass boost, treble boost, vocal, rock, pop, electronic, classical, loudness.

    Try it: !equalizer rock | !equalizer reset (the dashboard has sliders for every band)

    !join#

    Anyone can use it

    Makes Risk join your voice channel.

    !karaoke#

    Anyone can use it

    Toggles karaoke mode, which tries to remove the singer's voice.

    !loop#

    Anyone can use it

    Repeats the current song or the whole queue.

    Try it: !loop track | !loop queue | !loop off (no mode cycles through them)

    !nightcore#

    Anyone can use it

    Toggles nightcore (faster and higher).

    !nowplaying#

    Anyone can use it

    Shows the song that is playing, with a progress bar.

    !pause#

    Anyone can use it

    Pauses the music.

    !pitch#

    Anyone can use it

    Changes pitch from 0.5 to 2 (1 is normal).

    Try it: !pitch 1.2

    !play#

    Anyone can use it

    Plays a song or adds it to the queue. Takes a name or a YouTube, SoundCloud or Spotify link.

    Try it: !play never gonna give you up | !play https://youtu.be/...

    !queue#

    Anyone can use it

    Shows what is playing and what is coming up.

    Try it: !queue | !queue 2

    !queueclear#

    Anyone can use it

    Clears the queue but keeps the current song playing.

    !remove#

    Anyone can use it

    Removes a song from the queue by its number in !queue.

    Try it: !remove 3

    !resetfx#

    Anyone can use it

    Clears the equalizer, bass, speed, pitch, 8D and karaoke.

    !resume#

    Anyone can use it

    Resumes paused music.

    !seek#

    Anyone can use it

    Jumps to a time in the current song.

    Try it: !seek 1:30 | !seek 90

    !shufflequeue#

    Anyone can use it

    Shuffles the songs waiting in the queue.

    !skip#

    Anyone can use it

    Skips the current song.

    !speed#

    Anyone can use it

    Changes playback speed from 0.5 to 2 (1 is normal).

    Try it: !speed 1.25

    !stop#

    Anyone can use it

    Stops the music, clears the queue and leaves the voice channel.

    !volume#

    Anyone can use it

    Shows or sets the volume from 1 to 150.

    Try it: !volume | !volume 80

    No command matches that.
