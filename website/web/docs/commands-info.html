    Info commands

    Status, help and links. Anyone can use a command unless it says it needs a permission. If your server changed the prefix, use that instead of !.

    !bio#

    Anyone can use it

    Displays information from your Risk Bio website.

    !cogstatus#

    Anyone can use it

    Owner only. Shows which parts of the bot loaded and which failed.

    !commands#

    Anyone can use it

    Shows all commands and what they do.

    !dashboard#

    Anyone can use it

    Shows the link to the website dashboard where staff change Risk's settings.

    !forgetme#

    Anyone can use it

    Deletes everything Risk has saved about you (asks you to confirm first).

    !help#

    Anyone can use it

    Browse every command, or look up one.

    !mydata#

    Anyone can use it

    Sends you a copy of everything Risk has saved about you, in a private message.

    !ping#

    Anyone can use it

    Check the bot's latency.

    !prefix#

    Anyone can use it

    Shows or changes this server's extra prefix (the defaults ! ? , always work).

    Try it: !prefix $

    !privacy#

    Anyone can use it

    Shows what data Risk saves and how it is used.

    !time#

    Anyone can use it

    Shows the current time in UTC or a timezone.

    !tos#

    Anyone can use it

    Shows the server Terms of Service.

    !uptime#

    Anyone can use it

    Shows how long the bot has been online.

    No command matches that.
