    Fun commands

    Games, jokes and reactions. Anyone can use a command unless it says it needs a permission. If your server changed the prefix, use that instead of !.

    !8ball#

    Anyone can use it

    Asks the magic 8-ball a question.

    Try it: !8ball will it rain

    !acronym#

    Anyone can use it

    Makes a silly acronym out of a word.
