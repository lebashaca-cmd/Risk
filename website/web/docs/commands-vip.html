    VIP commands

    Extras for servers with VIP. Anyone can use a command unless it says it needs a permission. If your server changed the prefix, use that instead of !.

    !autodelete#

    Needs Manage Channels

    VIP Supreme. Deletes new messages in a channel after a delay.

    Try it: !autodelete set #channel <minutes> | off #channel | list

    !autodelete list#

    Needs Manage Channels

    Lists the channels.

    !autodelete off#

    Needs Manage Channels

    Stops deleting in a channel.

    Try it: !autodelete off #channel

    !autodelete set#

    Needs Manage Channels

    Deletes messages in the channel after some minutes.

    Try it: !autodelete set #channel <minutes>

    !autoreact#

    Anyone can use it

    VIP White. Reacts to messages that contain a word.

    Try it: !autoreact add <word> <emoji> | remove <word> | list

    !autoreact add#

    Needs Manage Server

    Reacts with an emoji whenever the word appears.

    Try it: !autoreact add <word> <emoji>

    !autoreact list#

    Anyone can use it

    Lists the auto reactions.

    !autoreact remove#

    Needs Manage Server

    Removes an auto reaction.

    Try it: !autoreact remove <word>

    !customcmd#

    Anyone can use it

    VIP White. Your own commands that reply with text.

    Try it: !customcmd add <name> <reply> | remove <name> | list

    !customcmd add#

    Needs Manage Server

    Adds a custom command.

    Try it: !customcmd add <name> <reply>

    !customcmd list#

    Anyone can use it

    Lists this server's custom commands.

    !customcmd remove#

    Needs Manage Server

    Removes a custom command.

    Try it: !customcmd remove <name>

    !embededit#

    Needs Manage Messages

    VIP White. Edits an embed Risk posted.

    Try it: !embededit <message id

    !founder#

    Anyone can use it

    VIP Lifetime. Shows this server's founding supporter card.

    !lockall#

    Needs Administrator

    VIP Supreme. Stops everyone from sending in every text channel.

    Try it: !lockall [reason]. Undo with !unlockall

    !membercounter#

    Needs Manage Channels

    VIP Supreme. Keeps a channel's name showing the member count.

    Try it: !membercounter set #voice [Members: {count}] | off

    !membercounter off#

    Needs Manage Channels

    Stops updating.

    !membercounter set#

    Needs Manage Channels

    Picks the channel.

    Try it: !membercounter set #channel [Members: {count}]

    !motd#

    Anyone can use it

    VIP Lifetime. Shows the server's message of the day.

    Try it: !motd (set with !motd set <text>, clear with !motd clear)

    !motd clear#

    Needs Manage Server

    Clears the message of the day.

    !motd set#

    Needs Manage Server

    Sets the message of the day.

    Try it: !motd set <text>

    !permaudit#

    Needs Administrator

    VIP Supreme. Shows which roles hold powerful permissions and how many members have them.

    !rolereport#

    Anyone can use it

    VIP. Lists a role's members, colour and permissions.

    Try it: !rolereport @role

    !schedule#

    Needs Manage Server

    VIP. Repeats a message in a channel.

    Try it: !schedule #channel 6h Your message

    !schedules#

    Needs Manage Server

    Lists this server's scheduled messages.

    !serverbackup#

    Needs Administrator

    VIP Supreme. Sends a file listing the server's roles and channels.

    !servercard#

    Anyone can use it

    VIP. Shows a card with the server's icon, banner and numbers.

    !serverstats#

    Anyone can use it

    VIP. Shows a detailed server report.

    !slowmodeall#

    Needs Manage Channels

    VIP Supreme. Sets slowmode on every text channel.

    Try it: !slowmodeall <seconds> (0 turns it off)

    !stafflist#

    Anyone can use it

    VIP White. Lists the staff, grouped by their top role.

    !topmessages#

    Anyone can use it

    VIP. Shows who sent the most messages (counted for levels).

    !unlockall#

    Needs Administrator

    VIP Supreme. Undoes !lockall and restores each channel.

    !unschedule#

    Needs Manage Server

    Removes a scheduled message.

    Try it: !unschedule <number>

    !userreport#

    Anyone can use it

    VIP. A detailed report on a member: dates, roles, level and money.

    Try it: !userreport [@member]

    !vip#

    Anyone can use it

    Shows this server's VIP status and what VIP unlocks.

    !vipannounce#

    Needs Manage Messages

    VIP. Posts an announcement embed and can ping one role.

    Try it: !vipannounce #channel [@role] Title | Body

    !vipcolor#

    Needs Manage Server

    VIP. Sets the accent colour of Risk's embeds here.

    Try it: !vipcolor #5865f2 (or !vipcolor reset)

    !vipcommands#

    Anyone can use it

    Lists every VIP command and which plan unlocks it.

    !vipembed#

    Needs Manage Messages

    VIP. Posts a custom embed.

    Try it: !vipembed #channel #5865f2 Title | Body text

    !vipgrant#

    Anyone can use it

    Owner only. Gives a server VIP for some days (0 = no end).

    Try it: !vipgrant <server id> [days] [basic|lifetime|white|supreme] [note]

    !viplist#

    Anyone can use it

    Owner only. Lists servers that have VIP.

    !vippoll#

    Needs Manage Messages

    VIP. Posts an embed poll with number reactions.

    Try it: !vippoll Question | Option 1 | Option 2 (up to 10)

    !viprevoke#

    Anyone can use it

    Owner only. Removes a server's VIP.

    Try it: !viprevoke <server id>

    !viprolecolor#

    Needs Manage Roles

    VIP. Changes a role's colour.

    Try it: !viprolecolor @role #ff0000

    !vipsay#

    Needs Manage Messages

    VIP. Makes Risk say something, in this or another channel.

    Try it: !vipsay [#channel] message

    !viptier#

    Anyone can use it

    Owner only. Changes which plan a VIP server is on.

    Try it: !viptier <server id> <basic|lifetime|white|supreme>

    !welcomedm#

    Needs Manage Server

    VIP White. Sends new members a private message.

    Try it: !welcomedm set <text> | off | show

    !welcomedm off#

    Needs Manage Server

    Turns it off.

    !welcomedm set#

    Needs Manage Server

    Sets the message.

    Try it: !welcomedm set <text>

    !welcomedm show#

    Needs Manage Server

    Shows the message.
