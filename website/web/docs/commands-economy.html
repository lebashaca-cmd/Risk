    Economy commands

    Coins, jobs, shops and gambling. Anyone can use a command unless it says it needs a permission. If your server changed the prefix, use that instead of !.

    !addmoney#

    Needs Administrator

    Adds or removes coins from someone's wallet.

    Try it: !addmoney @user 1000

    !balance#

    Anyone can use it

    Shows a wallet and bank balance.

    Try it: !balance @user

    !beg#

    Anyone can use it

    Begs for spare change.

    !bet#

    Anyone can use it

    Bets on a coin flip. Win to double it.

    Try it: !bet 100 heads

    !blackjack#

    Anyone can use it

    Plays blackjack against the dealer with buttons.

    Try it: !blackjack 500

    !buy#

    Anyone can use it

    Buys an item from the shop.

    Try it: !buy padlock 2

    !crime#

    Anyone can use it

    Attempts a risky crime for big coins, or a fine.

    !daily#

    Anyone can use it

    Claims your daily coins. Keep a streak for a bonus.

    !deposit#

    Anyone can use it

    Moves coins from your wallet to your bank.

    Try it: !deposit 500

    !dicebet#

    Anyone can use it

    Bets on the number a die will land on. A correct guess pays 5 to 1.

    Try it: !dicebet 100 4

    !fish#

    Anyone can use it

    Goes fishing with a rod.

    !gift#

    Anyone can use it

    Gives one of your shop items to another member.

    Try it: !gift @user padlock 1

    !give#

    Anyone can use it

    Gives some of your wallet coins to someone.

    Try it: !give @user 100

    !heist#

    Anyone can use it

    Starts a bank heist that others can join for 45 seconds.

    !highlow#

    Anyone can use it

    Guesses higher or lower to build a streak, then cash out.

    Try it: !highlow 200

    !hunt#

    Anyone can use it

    Hunts animals with a rifle for coins.

    !inventory#

    Anyone can use it

    Shows the items someone owns.

    Try it: !inventory @user

    !lottery#

    Anyone can use it

    Shows the lottery pot and your tickets. Actions: buy, info, draw.

    !lottery buy#

    Anyone can use it

    Buys lottery tickets for 100 coins each (up to 50 per person).

    Try it: !lottery buy 5

    !lottery draw#

    Needs Manage Server

    Draws the lottery now (staff only).

    !lottery info#

    Anyone can use it

    Shows the pot, the next draw and the last winner.

    !mine#

    Anyone can use it

    Mines for ore with a pickaxe.

    !monthly#

    Anyone can use it

    Claims your monthly coins.

    !networth#

    Anyone can use it

    Shows wallet, bank and item value added together.

    Try it: !networth @user

    !rob#

    Anyone can use it

    Tries to steal coins from someone's wallet.

    Try it: !rob @user

    !roulette#

    Anyone can use it

    Bets on a roulette spin: red, black, even, odd, low, high or a number 0-36.

    Try it: !roulette 500 red

    !scratch#

    Anyone can use it

    Scratches a card with 3 hidden boxes. Match symbols to win.

    Try it: !scratch 50

    !sell#

    Anyone can use it

    Sells an item back for half its price.

    Try it: !sell rod

    !shop#

    Anyone can use it

    Lists items you can buy.

    !slots#

    Anyone can use it

    Spins the slot machine.

    Try it: !slots 100

    !weekly#

    Anyone can use it

    Claims your weekly coins.

    !withdraw#

    Anyone can use it

    Moves coins from your bank to your wallet.

    Try it: !withdraw 500

    !work#

    Anyone can use it

    Works a shift for coins once an hour.

    No command matches that.
