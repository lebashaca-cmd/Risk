    Risk documentation

    Risk is a Discord bot for running a server: moderation, levels, an economy, tickets, logs, giveaways, stream alerts and a website dashboard where staff change settings without typing commands. These pages explain what it can do, how each part works and how to use it.

    439 commands in 14 categories, 57 message variables.

    Where to start#

    • New to Risk? Read Getting started to add the bot and set up the basics in a few minutes.
    • Prefer clicking to typing? The dashboard changes most settings from a web page.
    • Looking for one command? Use the search box at the top, or browse the command reference.
    • Want a custom welcome message? See Message templates and the variables you can use in them.

    How the pieces fit together#

    Risk is built from independent features. Each one works on its own, so you only set up what you want.

    • Commands start with a prefix. The defaults are !, ? and ,, and they always work. Staff can add one more prefix per server.
    • Permissions are checked every time. A command that needs Ban Members only works for people who can ban members in that server. See Permissions.
    • The dashboard is a website that edits the same settings the commands edit, so you can mix both freely.
    • VIP unlocks extra commands and larger limits for a server. See VIP plans. Everything else is free.

    Good to know#

    • What Risk keeps, and why, is spelled out in the privacy policy on the main site.
    • Staff with the Manage Server permission are never locked out by command rules or disabled commands, so you can always fix a mistake.
    • If something doesn't work, check Troubleshooting first. It lists the usual causes.
