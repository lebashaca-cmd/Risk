    AI commands

    Ask Risk a question. Anyone can use a command unless it says it needs a permission. If your server changed the prefix, use that instead of !.

    !aiquiz#

    Anyone can use it

    Makes a 5 question quiz on a topic with the answers hidden.

    Try it: !aiquiz the solar system

    !analogy#

    Anyone can use it

    Explains something with an analogy.

    Try it: !analogy how the internet works

    !ask#

    Anyone can use it

    Ask the AI a question. Code comes in code blocks, files get attached.

    Try it: !ask your question

    !caption#

    Anyone can use it

    Writes caption ideas for a photo or post.

    Try it: !caption my dog at the park

    !catchup#

    Anyone can use it

    Summarizes the last messages in this channel so you can catch up.

    Try it: !catchup 40 (up to 80)

    !characterbio#

    Anyone can use it

    Writes a character backstory from an idea.

    Try it: !characterbio a retired space pirate who bakes

    !codereview#

    Anyone can use it

    Reviews a piece of code and suggests improvements.

    Try it: !codereview <paste code>

    !commitmsg#

    Anyone can use it

    Writes a git commit message for your changes.

    Try it: !commitmsg fixed login bug where empty passwords passed

    !debatecase#

    Anyone can use it

    Argues both sides of a question.

    Try it: !debatecase should schools start later

    !dialogue#

    Anyone can use it

    Writes a short dialogue for a scene.

    Try it: !dialogue two robots arguing about pizza

    !dndhook#

    Anyone can use it

    Creates a tabletop adventure hook.

    Try it: !dndhook haunted lighthouse

    !dream#

    Anyone can use it

    Gives a playful reading of a dream (just for fun).

    Try it: !dream I was flying over my school

    !emaildraft#

    Anyone can use it

    Drafts an email from a short description.

    Try it: !emaildraft ask my teacher for a deadline extension, polite

    !etymology#

    Anyone can use it

    Explains where a word comes from.

    Try it: !etymology salary

    !expand#

    Anyone can use it

    Expands a short note into fuller text.

    Try it: !expand meeting moved to friday

    !explain#

    Anyone can use it

    Explains something in plain language.

    Try it: !explain how does wifi work

    !explaincode#

    Anyone can use it

    Explains what some code does.

    Try it: !explaincode <code>,

    !fallacy#

    Anyone can use it

    Spots logical fallacies in an argument.

    Try it: !fallacy Everyone I know likes it so it must be good

    !flashcards#

    Anyone can use it

    Makes flashcards for a topic.

    Try it: !flashcards photosynthesis

    !grammar#

    Anyone can use it

    Fixes spelling and grammar.

    Try it: !grammar i dont no what to rite

    !haiku#

    Anyone can use it

    Writes a haiku about a topic.

    Try it: !haiku autumn rain

    !hashtags#

    Anyone can use it

    Suggests hashtags for a post.

    Try it: !hashtags sunset at the beach

    !ideas#

    Anyone can use it

    Brainstorms ideas for something.

    !keywords#

    Anyone can use it

    Pulls the key words and topics out of text.

    Try it: !keywords <text>

    !lifehack#

    Anyone can use it

    !limerick#

    Anyone can use it

    !outline#

    Anyone can use it

    Try it: !whatif the moon disappeared
