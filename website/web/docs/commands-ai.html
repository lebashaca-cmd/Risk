    AI commands

    Ask Risk a question. Anyone can use a command unless it says it needs a permission. If your server changed the prefix, use that instead of !.

    !aiquiz#

    Anyone can use it

    Makes a 5 question quiz on a topic with the answers hidden.

    Try it: !aiquiz the solar system

    !ask#

    Anyone can use it

    Ask the AI a question. Code comes in code blocks, files get attached.

    Try it: !ask your question

    !catchup#

    Anyone can use it

    Summarizes the last messages in this channel so you can catch up.

    Try it: !catchup 40 (up to 80)

    !explain#

    Anyone can use it

    Explains something in plain language.

    Try it: !explain how does wifi work

    !explaincode#

    Anyone can use it

    Explains what some code does.

    Try it: !explaincode <code>,

    !grammar#

    Anyone can use it

    Fixes spelling and grammar.

    Try it: !grammar i dont no what to rite

    !ideas#

    Anyone can use it

    Brainstorms ideas for something.

    Try it: !ideas events for a gaming server

    !proscons#

    Anyone can use it

    Lists pros and cons.

    Try it: !proscons getting a dog

    !rewrite#

    Anyone can use it

    Rewrites text in a style.

    Try it: !rewrite formal hey can u send the file,

    !story#

    Anyone can use it

    Writes a short story from a prompt.

    Try it: !story a robot who learns to bake

    !suggestreply#

    Anyone can use it

    Suggests three ways to reply to a message.

    Try it: !suggestreply <message>,

    !summarize#

    Anyone can use it

    Summarizes some text, or the message you reply to.

    Try it: !summarize <text>

    !translate#

    Anyone can use it

    Translates text into a language.

    Try it: !translate spanish good morning,

    No command matches that.
