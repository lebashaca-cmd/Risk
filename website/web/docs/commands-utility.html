    Utility commands

    Handy tools: lookups, converters, reminders, server and user info. Anyone can use a command unless it says it needs a permission. If your server changed the prefix, use that instead of !.

    !adddays#

    Anyone can use it

    Adds (or subtracts) days from a date.

    Try it: !adddays 2026-11-11 100,

    !afk#

    Anyone can use it

    Marks you as away. Anyone who pings you is told.

    Try it: !afk lunch

    !anagram#

    Anyone can use it

    Checks whether two words are anagrams.

    Try it: !anagram listen silent

    !announce#

    Needs Manage Server

    Sends an announcement to a channel.

    Try it: !announce #news Server maintenance tonight

    !atbash#

    Anyone can use it

    Atbash cipher (a becomes z, b becomes y).

    Try it: !atbash hello

    !avatar#

    Anyone can use it

    Shows someone's avatar in full size.

    Try it: !avatar @user

    !banner#

    Anyone can use it

    Shows someone's profile banner.

    Try it: !banner @user

    !base#

    Anyone can use it

    Converts a number between bases 2 to 36.

    Try it: !base ff 16 2

    !base64#

    Anyone can use it

    Encodes or decodes Base64 text.

    Try it: !base64 encode hello

    !binary#

    Anyone can use it

    Converts text to binary, or binary back to text.

    Try it: !binary hi

    !botinfo#

    Anyone can use it

    Shows stats about the bot.

    !calc#

    Anyone can use it

    Does math with + - * / // % and **.

    Try it: !calc (12 + 8) * 3

    !camelcase#

    Anyone can use it

    Converts text to camelCase.

    Try it: !camelcase hello big world

    !channelinfo#
