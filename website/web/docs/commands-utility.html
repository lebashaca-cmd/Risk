    Utility commands

    Handy tools: lookups, converters, reminders, server and user info. Anyone can use a command unless it says it needs a permission. If your server changed the prefix, use that instead of !.

    !addemoji#

    Needs Manage Expressions

    Adds a custom emoji from an image link or attachment.

    Try it: !addemoji party https://example.com/party.png

    !admins#

    Anyone can use it

    Lists the members with Administrator permission.

    !afk#

    Anyone can use it

    Marks you as away. Anyone who pings you is told.

    Try it: !afk lunch

    !age#

    Anyone can use it

    Works out an age and the next birthday from a date.

    Try it: !age 2000-05-17

    !announce#

    Needs Manage Server

    Sends an announcement to a channel.

    Try it: !announce #news Server maintenance tonight

    !avatar#

    Anyone can use it

    Shows someone's avatar in full size.

    Try it: !avatar @user

    !average#

    Anyone can use it

    Gives the mean, median, mode, range and sum of some numbers.

    Try it: !average 4 8 15 16 23 42

    !banner#

    Anyone can use it

    Shows someone's profile banner.

    Try it: !banner @user

    !base64#

    Anyone can use it

    Encodes or decodes Base64 text.

    Try it: !base64 encode hello

    !binary#

    Anyone can use it

    Converts text to binary, or binary back to text.

    Try it: !binary hi

    !bmi#

    Anyone can use it

    Works out body mass index from kg and cm, or lb and inches.

    Try it: !bmi 70 175

    !boosters#

    Anyone can use it

    Lists the members boosting the server.

    !botinfo#

    Anyone can use it

    Shows stats about the bot.

    !bots#

    Anyone can use it

    Lists the bots in this server.

    !caesar#

    Anyone can use it

    Shifts the letters of some text, a Caesar cipher.

    Try it: !caesar 3 hello

    !calc#

    Anyone can use it

    Does math with + - * / // % and **.

    Try it: !calc (12 + 8) * 3

    !channelinfo#

    Anyone can use it

    Shows details about a channel.

    Try it: !channelinfo #general

    !charinfo#

    Anyone can use it

    Shows the Unicode name and code of each character.

    Try it: !charinfo é

    !color#

    Anyone can use it

    Previews a hex color.

    Try it: !color #ff8800

    !convert#

    Anyone can use it

    Converts length, mass, volume, speed and temperature units.

    Try it: !convert 10 km to mi

    !countdown#

    Anyone can use it

    Counts down to a UTC date and time.

    Try it: !countdown 2026-12-25 18:00

    !crypto#

    Anyone can use it

    Shows a cryptocurrency price in US dollars.

    Try it: !crypto eth

    !daysuntil#

    Anyone can use it

    Tells you how many days are left until a date.

    Try it: !daysuntil 2026-12-25

    !define#

    Anyone can use it

    Looks up the definition of a word.

    Try it: !define serendipity

    !editsnipe#

    Needs Manage Messages

    Shows the last edited message in this channel.

    !embed#

    Needs Manage Messages

    Posts an embed in a channel. Separate the title and text with a pipe.

    Try it: !embed #news Title | The text

    !emojiinfo#

    Anyone can use it

    Shows details about a custom emoji.

    Try it: !emojiinfo :name:

    !emojis#

    Anyone can use it

    Lists this server's custom emojis.

    !enlarge#

    Anyone can use it

    Shows a custom emoji at full size.

    Try it: !enlarge :custom_emoji:

    !epoch#

    Anyone can use it

    Converts between Unix time and a UTC date.

    Try it: !epoch 1798221600

    !firstmessage#

    Anyone can use it

    Links to the first message in this channel.

    !hash#

    Anyone can use it

    Hashes text with md5, sha1, sha256 or sha512.

    Try it: !hash sha256 hello

    !inrole#

    Anyone can use it

    !invite#

    Anyone can use it

    !joined#

    Anyone can use it

    !leetspeak#

    Anyone can use it

    !lowercase#

    !morse#

    !slugify#

    Try it: !slugify My Great Post!

    !snipe#

    Needs Manage Messages

    Anyone can use it

    Makes a Discord timestamp from a UTC date.

    Try it: !timestamp 2026-12-25 18:00

    Anyone can use it

    Try it: !titlecase the quick brown fox

    Anyone can use it

    !uppercase#

    Anyone can use it

    Try it: !uppercase hello

    !urlencode#

    Anyone can use it

    Encodes or decodes text for use in a link.

    Try it: !urlencode encode hello world

    !userinfo#

    Anyone can use it

    Try it: !userinfo @user

    Anyone can use it
