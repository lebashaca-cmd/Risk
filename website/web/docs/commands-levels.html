    Levels commands

    XP, ranks, leaderboards and level rewards. Anyone can use a command unless it says it needs a permission. If your server changed the prefix, use that instead of !.

    !addxp#

    Needs Manage Server

    Gives someone extra XP.

    Try it: !addxp @user 500

    !delreward#

    Needs Manage Roles

    Removes the reward for a level.

    Try it: !delreward 10

    !leaderboard#

    Anyone can use it

    Shows the top members with all of their stats. Sort by coins, wallet, bank, level, messages, streak, items or giveaways.

    Try it: !leaderboard level 2

    !levelchannel#

    Needs Manage Server

    Chooses where level-ups are announced: a #channel, here, or off.

    Try it: !levelchannel #levels

    !levelinfo#

    Anyone can use it

    Shows how levels are set up in this server.

    !levelmessage#

    Needs Manage Server

    Sets the level-up message using {user}, {name}, {level}, {xp}, {nextlevel}, {messages} and any other {variable}, or reset. Put {embed} at the start and the end to send it as an embed.

    Try it: !levelmessage {embed} Nice one {user}, level {level}! {embed}

    !levelreward#

    Needs Manage Roles

    Gives a role when members reach a level.

    Try it: !levelreward 10 @Regular

    !levelrewards#

    Anyone can use it

    Lists the roles given at each level.

    !levels#

    Anyone can use it

    Shows the most active members by XP, 10 per page.

    Try it: !levels 2

    !levelstats#

    Anyone can use it

    Shows level statistics for the server.

    !nextlevel#

    Anyone can use it

    Shows how much XP is left for the next level.

    Try it: !nextlevel @user

    !noxp#

    Needs Manage Server

    Toggles a channel or role that earns no XP.

    Try it: !noxp #bot-spam

    !profile#

    Anyone can use it

    Shows every stat Risk has for a member, with their rank in each.

    Try it: !profile @user

    !rank#

    Anyone can use it

    Shows someone's level and XP.

    Try it: !rank @user

    !removexp#

    Needs Manage Server

    Takes XP away from someone.

    Try it: !removexp @user 500

    !resetlevels#

    Needs Administrator

    Resets everyone's XP in this server.

    Try it: !resetlevels confirm

    !resetxp#

    Needs Manage Server

    Resets one person's XP and message count.

    Try it: !resetxp @user

    !rewardmode#

    Needs Manage Roles

    Chooses whether reward roles stack or only the newest is kept.

    Try it: !rewardmode replace

    !rewardsync#

    Needs Manage Roles

    Gives reward roles to members who already qualify.

    !setlevel#

    Needs Manage Server

    Sets someone to the start of a level.

    Try it: !setlevel @user 10

    !setxp#

    Needs Manage Server

    Sets someone's XP.

    Try it: !setxp @user 2500

    !xpcooldown#

    Needs Manage Server

    Sets how many seconds a member waits between XP gains.

    Try it: !xpcooldown 45

    !xpmultiplier#

    Needs Manage Server

    Sets how much XP each message earns, from 0.1 to 100.

    Try it: !xpmultiplier 2

    !xpneeded#

    Anyone can use it

    Shows the total XP needed to reach a level.

    Try it: !xpneeded 25

    No command matches that.
