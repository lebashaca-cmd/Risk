    Games commands

    Track Minecraft, Terraria and Steam game servers (CS2, Rust, ARK and more): who is online, who joined, and manage the server from Discord. Plus Fortnite stats. Anyone can use a command unless it says it needs a permission. If your server changed the prefix, use that instead of !.

    !fortnite#

    Anyone can use it

    Shows a player's Fortnite Battle Royale stats: wins, kills, K/D and more.

    Try it: !fortnite Ninja | !fortnite SomeName psn

    !gameserver#

    Anyone can use it

    Game servers: track who is online and manage the server from Discord. Works with Minecraft (Java and Bedrock), Steam games like CS2, Rust and ARK, and Terraria.

    Try it: !gameserver add | status | players | seen | top | list

    !gameserver add#

    Needs Manage Server

    Saves a game server.

    Try it: !gameserver add survival minecraft play.example.com:25565 (games: minecraft, bedrock, source, terraria)

    !gameserver feed#

    Needs Manage Server

    Posts joins, leaves and downtime in a channel.

    Try it: !gameserver feed #game-feed | off

    !gameserver kick#

    Needs Manage Server

    Kicks a player from the game server.

    Try it: !gameserver kick survival Steve griefing

    !gameserver list#

    Anyone can use it

    Lists the saved game servers and whether they are up.

    !gameserver map#

    Anyone can use it

    Shows the world name and the link to the live map (Dynmap or BlueMap) if one is set.

    Try it: !gameserver map survival

    !gameserver players#

    Anyone can use it

    Lists who is on a game server right now.

    Try it: !gameserver players survival

    !gameserver remove#

    Needs Manage Server

    Forgets a game server and its player history.

    Try it: !gameserver remove survival

    !gameserver reset#

    Needs Administrator

    Resets a Minecraft world: stops the server, deletes the world folders and starts it again. Needs the Pterodactyl panel settings. This cannot be undone.

    Try it: !gameserver reset survival reset-survival

    !gameserver restart#

    Needs Manage Server

    Restarts the game server. With a panel it restarts properly; otherwise it stops the server over RCON and your host has to start it again.

    Try it: !gameserver restart survival confirm

    !gameserver run#

    Needs Manage Server

    Runs a console command on the game server through RCON.

    Try it: !gameserver run survival time set day

    !gameserver save#

    Needs Manage Server

    Saves the world to disk.

    Try it: !gameserver save survival

    !gameserver say#

    Needs Manage Server

    Sends a message to everyone in the game.

    Try it: !gameserver say survival Restarting in 5 minutes

    !gameserver seen#

    Anyone can use it

    Shows whether a player is online and when they were last seen on this server's game servers.

    Try it: !gameserver seen Steve

    !gameserver set#

    Needs Manage Server

    Changes one setting: query_port, rcon_port, rcon_password, token, map, panel_url, panel_key, panel_id, track. Use off to clear one. Passwords are better set in the dashboard.

    Try it: !gameserver set survival rcon_port 25575

    !gameserver skin#

    Anyone can use it

    Shows a Minecraft player's skin.

    Try it: !gameserver skin Steve

    !gameserver status#

    Anyone can use it

    Shows whether a game server is up, who is on, the version and the ping.

    Try it: !gameserver status survival

    !gameserver top#

    Anyone can use it

    Shows who has spent the most time on a game server.

    Try it: !gameserver top survival

    !gameserver whitelist#

    Needs Manage Server

    Minecraft whitelist.

    Try it: !gameserver whitelist survival add Steve | remove Steve | list
