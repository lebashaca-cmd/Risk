    Server logs commands

    Record what happens in your server. Anyone can use a command unless it says it needs a permission. If your server changed the prefix, use that instead of !.

    !logchannel#

    Needs Manage Server

    Sends one log category to its own channel, or back to the main one with off.

    Try it: !logchannel voice #voice-logs

    !logevents#

    Needs Manage Server

    Lists every log category and whether it's on.

    !logignore#

    Needs Manage Server

    Stops logging message edits and deletes in a channel.

    Try it: !logignore #staff-chat

    !logignored#

    Needs Manage Server

    Lists the channels whose message logs are off.

    !logrecent#

    Needs View Audit Log

    Shows the most recent logged events since the bot started.

    Try it: !logrecent 15

    !logreset#

    Needs Manage Server

    Resets categories, extra channels and ignored channels to the defaults.

    Try it: !logreset confirm

    !logs#

    Needs Manage Server

    Sets the server log channel (deletes, edits, voice, roles).

    Try it: !logs #channel

    !logsearch#

    Needs View Audit Log

    Searches recent logged events for some text.

    Try it: !logsearch deleted

    !logstatus#

    Needs Manage Server

    Shows the log channel and the current log settings.

    !logtest#

    Needs Manage Server

    Sends a test message to the log channel.

    !logtoggle#

    Needs Manage Server

    Turns a log category off or on.

    Try it: !logtoggle voice

    !logunignore#

    Needs Manage Server

    Starts logging message edits and deletes in a channel again.

    Try it: !logunignore #staff-chat

    !loguser#

    Needs View Audit Log

    Shows recent logged events about a person.

    Try it: !loguser @user

    No command matches that.
