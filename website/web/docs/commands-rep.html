    Rep commands

    Anyone can use a command unless it says it needs a permission. If your server changed the prefix, use that instead of !.

    !rep#

    Needs Manage Server

    Shows the rep setup.

    Try it: !rep , !rep text discord.gg/risk, !rep channel #rep, !rep off, !rep test

    !rep channel#

    Needs Manage Server

    Picks the channel the embeds go to.

    Try it: !rep channel #rep

    !rep off#

    Needs Manage Server

    Turns rep posts off and forgets the text and channel.

    !rep test#

    Needs Manage Server

    Posts a sample embed in the rep channel.

    !rep text#

    Needs Manage Server

    Sets the text to look for, usually your server invite.

    Try it: !rep text discord.gg/risk

    No command matches that.
