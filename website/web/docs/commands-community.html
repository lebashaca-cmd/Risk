    Community commands

    Giveaways, starboard, birthdays, counting, reaction roles, tags and more. Anyone can use a command unless it says it needs a permission. If your server changed the prefix, use that instead of !.

    !approve#

    Needs Manage Messages

    Approves a suggestion, with an optional reason.

    Try it: !approve 12 great idea

    !autorole#

    Anyone can use it

    Shows the role new members get automatically.

    !autorole off#

    Needs Manage Roles

    Stops giving new members a role.

    !autorole set#

    Needs Manage Roles

    Gives new members a role when they join.

    Try it: !autorole set @Member

    !autorole show#

    Anyone can use it

    Shows the role new members get automatically.

    !birthday#

    Anyone can use it

    Shows a member's birthday. Also: set, remove, list, next.

    Try it: !birthday @user

    !birthday list#

    Anyone can use it

    Lists birthdays in this server by month.

    !birthday next#

    Anyone can use it

    Shows the next few birthdays.

    !birthday remove#

    Anyone can use it

    Removes your saved birthday.

    !birthday set#

    Anyone can use it

    Saves your birthday as month and day.

    Try it: !birthday set 05-17

    !birthdaychannel#

    Needs Manage Server

    Sets where birthday messages go, or turns them off.

    Try it: !birthdaychannel #birthdays

    !counting#

    Anyone can use it

    Shows the counting game status. Actions: set, off, reset.

    !counting off#

    Needs Manage Server

    Stops the counting game.

    !counting reset#

    Needs Manage Server

    Resets the count to zero.

    !counting set#

    Needs Manage Server

    Starts the counting game in a channel.

    Try it: !counting set #counting

    !deny#

    Needs Manage Messages

    Denies a suggestion, with an optional reason.

    Try it: !deny 12 not right now

    !giveaway#

    Needs Manage Server

    Starts a giveaway: duration, winners, prize. Also: start, drop, end, reroll, cancel, list, info, require.

    Try it: !giveaway 1h 2 Discord Nitro

    !giveaway cancel#

    Needs Manage Server

    Removes a giveaway without picking a winner.

    Try it: !giveaway cancel 123456789012345678

    !giveaway drop#

    Needs Manage Server

    Starts a drop where the first person to press Enter wins.

    Try it: !giveaway drop Free role

    !giveaway end#

    Needs Manage Server

    Ends a giveaway now and picks winners.

    Try it: !giveaway end 123456789012345678

    !giveaway info#

    Anyone can use it

    Shows a giveaway's entries and winners.

    Try it: !giveaway info 123456789012345678

    !giveaway list#

    Anyone can use it

    Lists the giveaways that are running.

    !giveaway require#

    Needs Manage Server

    Limits a giveaway to members with a role, or removes the limit with off.

    Try it: !giveaway require 123456789012345678 @Member

    !giveaway reroll#

    Needs Manage Server

    Picks new winners for a finished giveaway.

    Try it: !giveaway reroll 123456789012345678

    !giveaway start#

    Needs Manage Server

    Starts a giveaway with a time limit.

    Try it: !giveaway start 30m 1 Steam gift card

    !note#

    Needs Manage Messages

    Keeps private staff notes about members. Actions: add, list, remove.

    Try it: !note add @user trusted

    !note add#

    Needs Manage Messages

    Adds a staff note to a member.

    Try it: !note add @user helped in the last event

    !note list#

    Needs Manage Messages

    Shows the staff notes for a member.

    Try it: !note list @user

    !note remove#

    Needs Manage Messages

    Removes one staff note by its number.

    Try it: !note remove @user 2

    !reactionrole#

    Anyone can use it

    Gives roles when members react to a message. Use add, remove or list.

    Try it: !reactionrole list

    !reactionrole add#

    Needs Manage Roles

    Adds a reaction role to a message in this channel.

    Try it: !reactionrole add 123456789012345678 🎮 @Gamer

    !reactionrole list#

    Anyone can use it

    Lists the reaction roles in this server.

    !reactionrole remove#

    Needs Manage Roles

    Removes a reaction role from a message.

    Try it: !reactionrole remove 123456789012345678 🎮

    !report#

    Anyone can use it

    Reports a member to the staff team.

    Try it: !report @user spamming links

    !reportchannel#

    Needs Manage Server

    Sets the staff channel for member reports, or turns reports off.

    Try it: !reportchannel #reports

    !rules#

    Anyone can use it

    Shows this server's rules.

    !setrules#

    Needs Manage Server

    Saves the server rules shown by the rules command, or reset to clear them.

    Try it: !setrules 1. Be kind. 2. No spam.

    !starboard#

    Anyone can use it

    Shows the starboard settings.

    !starboard off#

    Needs Manage Server

    Turns the starboard off.

    !starboard set#

    Needs Manage Server

    Chooses the starboard channel.

    Try it: !starboard set #starboard

    !starboard show#

    Anyone can use it

    Shows the starboard channel and star threshold.

    !starboard threshold#

    Needs Manage Server

    Sets how many stars a message needs, from 1 to 25.

    Try it: !starboard threshold 5

    !streamalerts#

    Needs Manage Server

    Sets the channel for stream alerts, and optionally a role to ping.

    Try it: !streamalerts #streams @StreamPing (or !streamalerts off)

    !streamalerts off#

    Needs Manage Server

    Turns stream alerts off.

    !streamers#

    Anyone can use it

    Ranks members by total time streamed.

    !streaming#

    Anyone can use it

    Shows who is streaming right now.

    !streamrole#

    Needs Manage Server

    Picks a role to ping when someone starts streaming (leave empty to stop pinging).

    Try it: !streamrole @Streams

    !streamstats#

    Anyone can use it

    Shows a member's stream count, total time and last stream.

    Try it: !streamstats @user

    !streamtest#

    Needs Manage Server

    Posts a sample 'is live' and 'stopped' alert in the alert channel.

    !suggest#

    Anyone can use it

    Posts a suggestion for the server to vote on.

    Try it: !suggest add a music channel

    !suggestchannel#

    Needs Manage Server

    Sets the channel suggestions are posted in, or turns them off.

    Try it: !suggestchannel #suggestions

    !tag#

    Anyone can use it

    Shows a saved tag. Manage them with tag add, edit, remove, list and info.

    Try it: !tag rules

    !tag add#

    Anyone can use it

    Creates a tag.

    Try it: !tag add rules Be kind to each other

    !tag edit#

    Anyone can use it

    Changes a tag's text.

    Try it: !tag edit rules Be kind and have fun

    !tag info#

    Anyone can use it

    Shows who made a tag and how often it's used.

    Try it: !tag info rules

    !tag list#

    Anyone can use it

    Lists the tags in this server.

    Try it: !tag list 2

    !tag remove#

    Anyone can use it

    Deletes a tag.

    Try it: !tag remove rules

    !tags#

    Anyone can use it

    Lists the tags in this server.

    !tiktokadd#

    Needs Manage Server

    Watches a TikTok account and posts when it goes live and ends.

    Try it: !tiktokadd @name @StreamPing

    !tiktoklist#

    Anyone can use it

    Lists the TikTok accounts this server watches.

    !tiktokremove#

    Needs Manage Server

    Stops watching a TikTok account.

    Try it: !tiktokremove @name

    !tiktoktest#

    Needs Manage Server

    Checks one TikTok account right now and says what Risk sees.

    Try it: !tiktoktest @name

    !twitchadd#

    Needs Manage Server

    Watches a Twitch channel and posts when it goes live and offline.

    Try it: !twitchadd shroud @StreamPing

    !twitchlist#

    Anyone can use it

    Lists the Twitch channels this server watches.

    !twitchremove#

    Needs Manage Server

    Stops watching a Twitch channel.

    Try it: !twitchremove shroud

    !twitchtest#

    Needs Manage Server

    Checks one Twitch channel right now and shows what the alert looks like.

    Try it: !twitchtest shroud

    !verifysetup#

    Needs Manage Roles

    Posts a Verify button that gives a role to whoever presses it.

    Try it: !verifysetup #verify @Member

    No command matches that.
