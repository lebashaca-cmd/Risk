    Tickets commands

    A support desk with panels, claims, notes and transcripts. Anyone can use a command unless it says it needs a permission. If your server changed the prefix, use that instead of !.

    !delpanel#

    Needs Manage Server

    Turns off a ticket panel by its message ID.

    Try it: !delpanel 123456789012345678

    !setlogs#

    Needs Manage Server

    Sets the log channel for tickets.

    Try it: !setlogs #channel

    !ticket#

    Needs Manage Channels

    Posts the ticket panel.

    Try it: !ticket "category_id" @staff

    !ticketadd#

    Anyone can use it

    Adds someone to the current ticket.

    Try it: !ticketadd @user

    !ticketclaim#

    Anyone can use it

    Claims the current ticket so others know you're handling it.

    !ticketclose#

    Anyone can use it

    Closes the current ticket with a reason and saves a transcript to the log channel.

    Try it: !ticketclose resolved

    !ticketinfo#

    Anyone can use it

    Shows details about a ticket.

    Try it: !ticketinfo #ticket-name

    !ticketlock#

    Anyone can use it

    Stops the ticket's opener from sending messages.

    !ticketnote#

    Anyone can use it

    Saves a private staff note on the ticket and hides your message.

    Try it: !ticketnote customer wants a refund

    !ticketnotes#

    Anyone can use it

    Sends you this ticket's staff notes by direct message.

    !ticketpanels#

    Needs Manage Server

    Lists the ticket panels that are active.

    !ticketping#

    Anyone can use it

    Pings the ticket's opener to ask for a reply.

    !ticketpriority#

    Anyone can use it

    Sets the ticket priority: low, normal, high or urgent.

    Try it: !ticketpriority high

    !ticketremove#

    Anyone can use it

    Removes someone from the current ticket.

    Try it: !ticketremove @user

    !ticketrename#

    Anyone can use it

    Renames the current ticket channel.

    Try it: !ticketrename billing-issue

    !tickets#

    Needs Manage Channels

    Lists the open tickets in this server.

    !ticketstats#

    Needs Manage Channels

    Shows a summary of open tickets.

    !ticketunclaim#

    Anyone can use it

    Releases your claim on the current ticket.

    !ticketunlock#

    Anyone can use it

    Lets the ticket's opener send messages again.

    !transcript#

    Anyone can use it

    Sends a text transcript of the current ticket without closing it.

    No command matches that.
