    Moderation commands

    Keep the server safe: bans, timeouts, locks, auto-mod and bulk tools. Anyone can use a command unless it says it needs a permission. If your server changed the prefix, use that instead of !.

    !addrole#

    Needs Manage Roles

    Gives one role to a member.

    Try it: !addrole @user @Member

    !antiinvite#

    Needs Manage Server

    Deletes messages with Discord invite links.

    Try it: !antiinvite on

    !antilink#

    Needs Manage Server

    Deletes messages with links from members who can't manage messages.

    Try it: !antilink on

    !antispam#

    Needs Manage Server

    Deletes message floods and times the sender out for 5 minutes.

    Try it: !antispam on

    !automod#

    Needs Manage Server

    Shows which automod protections are on.

    !automodignore#

    Needs Manage Server

    Toggles a channel or role that automod leaves alone.

    Try it: !automodignore #staff-chat

    !badwords#

    Needs Manage Server

    Manages words that get a message deleted. Actions: add, import, remove, list, clear.

    Try it: !badwords add word

    !badwords add#

    Needs Manage Server

    Blocks a word or short phrase. Your command message is deleted so the word isn't shown.

    Try it: !badwords add word

    !badwords clear#

    Needs Manage Server

    Removes every blocked word.

    Try it: !badwords clear confirm

    !badwords import#

    Needs Manage Server

    Blocks every word in an attached .txt or .env file (one per line, or comma separated).

    Try it: !badwords import (attach the file)

    !badwords list#

    Needs Manage Server

    Sends you the blocked words in a direct message.

    !badwords remove#

    Needs Manage Server

    Unblocks a word.

    Try it: !badwords remove word

    !ban#

    Needs Ban Members

    Bans a member from the server.

    Try it: !ban @user reason

    !banlist#

    Needs Ban Members

    Shows the first 25 banned users.

    !clear#

    Needs Manage Messages

    Deletes a specified number of messages.

    Try it: !clear 10

    !clearwarnings#

    Needs Manage Server

    Clears every warning for a member.

    Try it: !clearwarnings @user

    !clonechannel#

    Needs Manage Channels

    Makes a copy of a text channel with the same permissions.

    Try it: !clonechannel #general

    !createchannel#

    Needs Manage Channels

    Creates a text or voice channel.

    Try it: !createchannel text general-2

    !createrole#

    Needs Manage Roles

    Creates a role with no permissions.

    Try it: !createrole Event Team

    !deletechannel#

    Needs Manage Channels

    Deletes a channel (this one if you name none) after you confirm.

    Try it: !deletechannel #old-chat

    !deleterole#

    Needs Manage Roles

    Deletes a role.

    Try it: !deleterole @Old Role

    !delwarn#

    Needs Manage Messages

    Removes one warning by its number.

    Try it: !delwarn @user 2

    !hide#

    Needs Manage Channels

    Hides a channel from @everyone.

    Try it: !hide #channel

    !idban#

    Needs Ban Members

    Bans someone by ID, even if they aren't in the server.

    Try it: !idban 123456789 reason

    !kick#

    Needs Kick Members

    Kicks a member from the server.

    Try it: !kick @user reason

    !lock#

    Needs Manage Channels

    Stops @everyone from sending messages in a channel.

    Try it: !lock #channel

    !lockdown#

    Needs Manage Channels

    Stops @everyone from sending messages in every text channel.

    Try it: !lockdown raid

    !maxmentions#

    Needs Manage Server

    Deletes messages that mention more than a number of people or roles, or 0 to turn off.

    Try it: !maxmentions 5

    !nick#

    Needs Manage Nicknames

    Changes or resets a member's nickname.

    Try it: !nick @user New Name

    !nuke#

    Needs Manage Channels

    Clones this channel and deletes the old one to wipe all messages.

    Try it: !nuke confirm

    !purgebots#

    Needs Manage Messages

    Deletes recent messages sent by bots.

    Try it: !purgebots 50

    !purgeuser#

    Needs Manage Messages

    Deletes one member's recent messages from this channel.

    Try it: !purgeuser @user 50

    !r#

    Anyone can use it

    Gives a member a role by name.

    Try it: !r @user ROLE

    !removerole#

    Needs Manage Roles

    Takes a role away from a member.

    Try it: !removerole @user Role

    !renamechannel#

    Needs Manage Channels

    Renames a channel.

    Try it: !renamechannel #general chat-room

    !resetnick#

    Needs Manage Nicknames

    Clears a member's nickname.

    Try it: !resetnick @user

    !roleall#

    Needs Manage Roles

    Gives a role to every member who doesn't have it.

    Try it: !roleall @Member

    !rolecolor#

    Needs Manage Roles

    Changes a role's color.

    Try it: !rolecolor @Member #ff8800

    !rolename#

    Needs Manage Roles

    Renames a role.

    Try it: !rolename @Member Verified Member

    !settopic#

    Needs Manage Channels

    Sets this channel's topic, or use clear to remove it.

    Try it: !settopic Daily chat

    !slowmode#

    Needs Manage Channels

    Sets slowmode in a channel, or turns it off.

    Try it: !slowmode 10s

    !softban#

    Needs Ban Members

    Bans and unbans a member to delete their recent messages.

    Try it: !softban @user reason

    !tempban#

    Needs Ban Members

    Bans a member and unbans them automatically later.

    Try it: !tempban @user 3d reason

    !tempbans#

    Needs Ban Members

    Lists the temporary bans that will end on their own.

    !timeout#

    Needs Moderate Members

    Times a member out so they can't talk.

    Try it: !timeout @user 10m reason

    !unban#

    Needs Ban Members

    Unbans a user by their ID.

    Try it: !unban 123456789

    !unbanall#

    Needs Administrator

    Unbans everyone in this server after you confirm.

    !unhide#

    Needs Manage Channels

    Shows a hidden channel to @everyone again.

    Try it: !unhide #channel

    !unlock#

    Needs Manage Channels

    Lets @everyone send messages in a channel again.

    Try it: !unlock #channel

    !unlockdown#

    Needs Manage Channels

    Lets @everyone send messages again in every text channel.

    !unroleall#

    Needs Manage Roles

    Takes a role away from every member who has it.

    Try it: !unroleall @Member

    !untimeout#

    Needs Moderate Members

    Removes a timeout from a member.

    Try it: !untimeout @user

    !vcdeafen#

    Needs Deafen Members

    Server-deafens a member in voice.

    Try it: !vcdeafen @user

    !vcdisconnectall#

    Needs Move Members

    Disconnects everyone from your voice channel except you.

    !vckick#

    Needs Move Members

    Disconnects a member from voice.

    Try it: !vckick @user

    !vcmove#

    Needs Move Members

    Moves a member to another voice channel.

    Try it: !vcmove @user General

    !vcmute#

    Needs Mute Members

    Server-mutes a member in voice.

    Try it: !vcmute @user

    !vcmuteall#

    Needs Mute Members

    Mutes or unmutes everyone in your voice channel except you.

    Try it: !vcmuteall on

    !vcundeafen#

    Needs Deafen Members

    Removes a server deafen in voice.

    Try it: !vcundeafen @user

    !vcunmute#

    Needs Mute Members

    Removes a server mute in voice.

    Try it: !vcunmute @user

    !warn#

    Needs Manage Messages

    Warns a member and records it.

    Try it: !warn @user reason

    !warnings#

    Needs Manage Messages

    Lists the warnings a member has.

    Try it: !warnings @user

    No command matches that.
