# Glossary

- **Cog**: a Python file of related commands and listeners that discord.py loads as one unit.
- **Snowflake**: a Discord id, a large number sent as text so it does not lose digits.
- **Guild**: Discord's word for a server.
- **Manager**: someone with Administrator or Manage Server. Bypasses command rules, disabled commands and ignored channels.
- **Section**: one tab of the dashboard and its saved settings.
- **JsonStore**: Risk's small file store, written atomically.
- **Go Live**: Discord screen sharing in a voice channel.
- **Presence intent**: a privileged gateway permission that lets a bot see members' statuses and activities.
- **Helix**: Twitch's current API.
- **CSP**: Content Security Policy, the browser rule list the site sends.
- **CSRF**: tricking a signed-in browser into sending a change. Blocked by a custom header and Origin check.
- **SPA**: single-page app, the website's front end.
- **VIP**: a per-server upgrade unlocking extras. Granted by the owner.
- **Embed tag**: `{embed}` at the start and end of a message to send it as an embed.
