# Welcome commands

2 commands. Run `!help <command>` or see the examples below.

- **welcome** (needs Manage Server): Greets new members in a channel. Write New_user where the name goes. Put {embed} at the start and the end to send it as an embed. Example: `#channel {embed} Welcome New_user to Risk {embed}`
- **welcomeoff** (needs Manage Server): Turns welcome messages off.
