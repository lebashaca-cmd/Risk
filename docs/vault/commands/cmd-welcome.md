# Welcome commands

2 commands. Run `!help <command>` or see the examples below.

- **welcome** (needs Manage Server): Greets new members in a channel. Write New_user where the name goes. Example: `#channel Welcome New_user to Risk`
- **welcomeoff** (needs Manage Server): Turns welcome messages off.
