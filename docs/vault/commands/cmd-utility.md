# Utility commands

72 commands. Run `!help <command>` or see the examples below.

- **addemoji** (needs Manage Expressions): Adds a custom emoji from an image link or attachment. Example: `party https://example.com/party.png`
- **admins**: Lists the members with Administrator permission.
- **afk**: Marks you as away. Anyone who pings you is told. Example: `lunch`
- **age**: Works out an age and the next birthday from a date. Example: `2000-05-17`
- **announce** (needs Manage Server): Sends an announcement to a channel. Example: `#news Server maintenance tonight`
- **avatar**: Shows someone's avatar in full size. Example: `@user`
- **average**: Gives the mean, median, mode, range and sum of some numbers. Example: `4 8 15 16 23 42`
- **banner**: Shows someone's profile banner. Example: `@user`
- **base64**: Encodes or decodes Base64 text. Example: `encode hello`
- **binary**: Converts text to binary, or binary back to text. Example: `hi`
- **bmi**: Works out body mass index from kg and cm, or lb and inches. Example: `70 175`
- **boosters**: Lists the members boosting the server.
- **botinfo**: Shows stats about the bot.
- **bots**: Lists the bots in this server.
- **caesar**: Shifts the letters of some text, a Caesar cipher. Example: `3 hello`
- **calc**: Does math with + - * / // % and **. Example: `(12 + 8) * 3`
- **channelinfo**: Shows details about a channel. Example: `#general`
- **charinfo**: Shows the Unicode name and code of each character. Example: `é`
- **color**: Previews a hex color. Example: `#ff8800`
- **convert**: Converts length, mass, volume, speed and temperature units. Example: `10 km to mi`
- **countdown**: Counts down to a UTC date and time. Example: `2026-12-25 18:00`
- **crypto**: Shows a cryptocurrency price in US dollars. Example: `eth`
- **daysuntil**: Tells you how many days are left until a date. Example: `2026-12-25`
- **define**: Looks up the definition of a word. Example: `serendipity`
- **editsnipe** (needs Manage Messages): Shows the last edited message in this channel.
- **embed** (needs Manage Messages): Posts an embed in a channel. Separate the title and text with a pipe. Example: `#news Title | The text`
- **emojiinfo**: Shows details about a custom emoji. Example: `:name:`
- **emojis**: Lists this server's custom emojis.
- **enlarge**: Shows a custom emoji at full size. Example: `:custom_emoji:`
- **epoch**: Converts between Unix time and a UTC date. Example: `1798221600`
- **firstmessage**: Links to the first message in this channel.
- **hash**: Hashes text with md5, sha1, sha256 or sha512. Example: `sha256 hello`
- **inrole**: Lists members who have a role. Example: `Moderator`
- **invite**: Gives the link to add the bot to a server.
- **joined**: Shows when someone joined and their join position. Example: `@user`
- **leetspeak**: Writes text in leetspeak. Example: `elite hacker`
- **lowercase**: Turns text into lowercase. Example: `HELLO`
- **membercount**: Shows how many members the server has.
- **morse**: Converts text to Morse code, or Morse code back to text. Example: `hello world`
- **newest**: Lists the members who joined most recently.
- **oldest**: Lists the members who joined first. Example: `2`
- **palette**: Builds a five-colour palette from one hex colour. Example: `#5865F2`
- **password**: Sends you a random password in a direct message. Example: `20`
- **percent**: Works out percentages between two numbers. Example: `20 150`
- **permissions**: Lists the permissions a member has here. Example: `@user`
- **poll**: Starts a reaction poll. Example: `Pizza`
- **pypi**: Looks up a Python package on PyPI. Example: `requests`
- **qr**: Makes a QR code from text or a link. Example: `https://example.com`
- **reminders**: Lists your pending reminders.
- **remindme**: Reminds you later in this channel. Example: `1h take out the trash`
- **removeemoji** (needs Manage Expressions): Deletes a custom emoji from this server. Example: `:party:`
- **roleinfo**: Shows details about a role. Example: `Moderator`
- **roles**: Lists every role in the server.
- **roman**: Converts a number to a Roman numeral, or back. Example: `2026`
- **rot13**: Applies the ROT13 letter swap. Example: `hello`
- **serverbanner**: Shows the server banner.
- **servericon**: Shows the server icon.
- **serverinfo**: Shows information about the server.
- **slugify**: Turns text into a url-friendly slug. Example: `My Great Post!`
- **snipe** (needs Manage Messages): Shows the last deleted message in this channel.
- **snowflake**: Shows when a Discord ID was created. Example: `123456789012345678`
- **timestamp**: Makes a Discord timestamp from a UTC date. Example: `2026-12-25 18:00`
- **titlecase**: Turns text Into Title Case. Example: `the quick brown fox`
- **todo**: Keeps a personal to-do list. Actions: add, list, done, remove, clear. Example: `add buy milk`
- **uppercase**: Turns text into UPPERCASE. Example: `hello`
- **urlencode**: Encodes or decodes text for use in a link. Example: `encode hello world`
- **userinfo**: Shows information about a user. Example: `@user`
- **uuid**: Generates random UUIDs. Example: `3`
- **weather**: Shows the current weather for a city. Example: `Chicago`
- **whohas**: Lists the members that have a role. Example: `@Moderators`
- **wiki**: Shows the summary of a Wikipedia article. Example: `Alan Turing`
- **wordcount**: Counts the words, characters and sentences in some text. Example: `some text here`
