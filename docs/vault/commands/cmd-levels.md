# Levels commands

24 commands. Run `!help <command>` or see the examples below.

- **addxp** (needs Manage Server): Gives someone extra XP. Example: `@user 500`
- **delreward** (needs Manage Roles): Removes the reward for a level. Example: `10`
- **leaderboard**: Shows the top members with all of their stats. Sort by coins, wallet, bank, level, messages, streak, items or giveaways. Example: `level 2`
- **levelchannel** (needs Manage Server): Chooses where level-ups are announced: a #channel, here, or off. Example: `#levels`
- **levelinfo**: Shows how levels are set up in this server.
- **levelmessage** (needs Manage Server): Sets the level-up message using {user}, {name} and {level}, or reset. Example: `Nice one {user}, level {level}!`
- **levelreward** (needs Manage Roles): Gives a role when members reach a level. Example: `10 @Regular`
- **levelrewards**: Lists the roles given at each level.
- **levels**: Shows the most active members by XP, 10 per page. Example: `2`
- **levelstats**: Shows level statistics for the server.
- **nextlevel**: Shows how much XP is left for the next level. Example: `@user`
- **noxp** (needs Manage Server): Toggles a channel or role that earns no XP. Example: `#bot-spam`
- **profile**: Shows every stat Risk has for a member, with their rank in each. Example: `@user`
- **rank**: Shows someone's level and XP. Example: `@user`
- **removexp** (needs Manage Server): Takes XP away from someone. Example: `@user 500`
- **resetlevels** (needs Administrator): Resets everyone's XP in this server. Example: `confirm`
- **resetxp** (needs Manage Server): Resets one person's XP and message count. Example: `@user`
- **rewardmode** (needs Manage Roles): Chooses whether reward roles stack or only the newest is kept. Example: `replace`
- **rewardsync** (needs Manage Roles): Gives reward roles to members who already qualify.
- **setlevel** (needs Manage Server): Sets someone to the start of a level. Example: `@user 10`
- **setxp** (needs Manage Server): Sets someone's XP. Example: `@user 2500`
- **xpcooldown** (needs Manage Server): Sets how many seconds a member waits between XP gains. Example: `45`
- **xpmultiplier** (needs Manage Server): Sets how much XP each message earns, from 0.1 to 100. Example: `2`
- **xpneeded**: Shows the total XP needed to reach a level. Example: `25`
