# Lookups commands

4 commands. Run `!help <command>` or see the examples below.

- **github**: Shows a GitHub profile or repo. Example: `username`
- **spotify**: Searches Spotify or shows a link. Example: `song name`
- **tiktok**: Shows a TikTok profile. Example: `username`
- **youtube**: Shows a YouTube video, channel or playlist, or searches. Example: `@channel`
