# Info commands

10 commands. Run `!help <command>` or see the examples below.

- **bio**: Displays information from your Risk Bio website.
- **cogstatus**: Owner only. Shows which parts of the bot loaded and which failed.
- **commands**: Shows all commands and what they do.
- **dashboard**: Shows the link to the website dashboard where staff change Risk's settings.
- **ping**: Check the bot's latency.
- **prefix**: Shows or changes this server's extra prefix (the defaults ! ? , always work). Example: `$`
- **privacy**: Shows what data Risk saves and how it is used.
- **time**: Shows the current time in UTC or a timezone.
- **tos**: Shows the server Terms of Service.
- **uptime**: Shows how long the bot has been online.
